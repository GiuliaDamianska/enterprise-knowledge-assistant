# Security

This document describes the security decisions made in this project and the threats they address.

## Credential Management

**Decision:** All API keys and configuration values are loaded exclusively from environment variables (via `.env` using `python-dotenv`). No secrets appear in source code, configuration files, or command-line arguments.

**Threat mitigated:** Accidental credential exposure via version control or process listings.

**Implementation:**
- `.env` is listed in `.gitignore` and is never committed.
- `.env.example` contains only placeholder values.
- Each component validates that its required key is present at startup, failing fast with a clear error message rather than silently using a null/empty key.

---

## Path Traversal Prevention

**Decision:** The `read_document` MCP tool resolves all caller-supplied paths to their canonical absolute form using `Path.resolve()` before performing any file I/O, then verifies the result is inside `DOCS_DIR` using `Path.is_relative_to()`.

**Threat mitigated:** An attacker (or misbehaving MCP client) supplying paths like `../../etc/passwd`, `../../../.env`, or symlinks pointing outside `DOCS_DIR` to read arbitrary files from the host.

**Implementation (`mcp-servers/knowledge-server/server.py`):**
```python
def _safe_resolve(requested_path: str) -> Path:
    if os.path.isabs(requested_path):
        raise ValueError("Absolute paths are not permitted.")
    resolved = (DOCS_DIR / requested_path).resolve()   # follows symlinks
    if not resolved.is_relative_to(DOCS_DIR):           # final boundary check
        raise ValueError("Path traversal attempt blocked.")
    return resolved
```

**Why both steps?**
- `Path.resolve()` eliminates `..` sequences and follows symlinks, so the result is always a real absolute path.
- `is_relative_to()` then confirms the real path is still inside `DOCS_DIR`, preventing symlink-based escapes.

## File Type Whitelist

**Decision:** `read_document` only permits `.txt`, `.md`, and `.pdf` file extensions. All other types are rejected before any I/O occurs.

**Threat mitigated:** Accidental exposure of sensitive files (`.env`, `.py`, `.db`, `.key`, private keys, etc.) that happen to reside inside `DOCS_DIR`.

**Implementation:** A `frozenset` of permitted extensions is defined at module level. Extension matching uses `.lower()` to prevent case-bypass (e.g. `.PDF`, `.Pdf`).

---

## Append-Only Audit Log

**Decision:** The audit log file is opened with `mode='a'` (append) and Python's `logging.FileHandler`. Log propagation is disabled to prevent entries reaching unintended handlers.

**Threat mitigated:** Accidental or deliberate erasure of audit history by application code. The log serves as a forensic record; overwrite-prevention is essential.

**Implementation (`src/audit/logger.py`):**
```python
handler = logging.FileHandler(log_path, mode="a", encoding="utf-8")
logger.propagate = False
```

**OS-level hardening (recommended for production):**
```bash
# Make the log file append-only at the OS level (Linux)
sudo chattr +a logs/audit.log
```
This prevents even root from truncating the file without first removing the attribute.

## Grounded Prompt Design

**Decision:** The query engine instructs Claude to answer *only* from the retrieved context chunks, not from its training data.

**Threat mitigated:** Hallucination of false information attributed to company documents; prompt injection attacks embedded in documents.

**Implementation (`src/query/engine.py`):**
```python
system_prompt = (
    "Answer questions using ONLY the context provided below. "
    "If the answer cannot be found in the context, say so clearly "
    "and do not speculate."
)
```

**Limitation:** This is a prompt-level control, not a hard technical constraint. For high-stakes use cases, add output validation or human review of answers.

---

## Input Validation

**Decision:** All external inputs (file paths, questions) are validated before processing. Invalid inputs are rejected with descriptive errors rather than silently ignored or partially processed.

**Threat mitigated:** Unexpected behaviour from malformed inputs; information leakage via error messages (errors are descriptive but do not reveal internal paths or system details).

---

## Dependency Pinning

**Decision:** Direct dependencies are pinned to minimum versions in `pyproject.toml`. The `uv.lock` file (generated by `uv lock`) pins transitive dependencies to exact versions.

**Threat mitigated:** Supply-chain attacks via malicious package updates; unexpected breaking changes.

**Recommendation:** Run `uv audit` (or `pip-audit`) periodically to check for known vulnerabilities in dependencies.

---

## No Hardcoded Secrets

**Verification:** Search for hardcoded secrets before deploying:
```bash
grep -r "sk-ant-" src/ mcp-servers/ scripts/   # Anthropic keys
grep -r "pa-" src/ mcp-servers/ scripts/         # Voyage AI keys
grep -rE "(password|secret|token)\s*=" src/ mcp-servers/ scripts/
```

All searches should return no results. If any do, the match must be reviewed immediately.
